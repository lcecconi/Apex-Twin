# 3D CAD Models & Enclosures

This directory houses the mechanical 3D CAD design files, assemblies, and enclosure models for the Apex-Twin telemetry ecosystem.

## Modules

* **[Apex-Dash 3D CAD Enclosure](apex-dash/README.md):** SolidCraft parametric models for the steering-wheel HUD display enclosure (front bezel, rear pod, screen glass, USB-C bulkhead, and master assembly).

## Git LFS

All parametric container files (`*.sc`) are tracked via **Git LFS** (configured in the repository root `.gitattributes`). Make sure Git LFS is installed and initialized on your system (`git lfs install`).
